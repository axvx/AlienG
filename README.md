# 3D Marine vs Aliens - Tactical Bomb

¡Bienvenido a **3D Marine vs Aliens**, un juego de disparos pseudo-3D desarrollado en HTML5 Canvas y JavaScript puro!

En este juego tomas el papel de un Marine espacial que debe defenderse de una horda de alienígenas utilizando tu arma principal y bombas tácticas (Smart Bombs). El juego cuenta con efectos de sonido integrados, gráficos vectoriales generados por código y un sistema de radar para advertir la proximidad de los enemigos.

## 🎮 Controles

- **Moverte:** `A` / `D` o las flechas `←` / `→`
- **Disparar:** `C`
- **Bomba Táctica:** `X` (Destruye a todos los alienígenas en pantalla. Tienes un máximo de 3).
- **Reiniciar (cuando pierdes):** `R`

## 🚀 Características

- **Gráficos pseudo-3D:** Efecto visual inmersivo creado únicamente con dibujo en un Canvas 2D.
- **Audio generativo:** Todos los efectos de sonido (disparos, explosiones, sirenas de advertencia) se generan matemáticamente en tiempo real usando el `AudioContext` de JavaScript (sin necesidad de archivos `.mp3` ni `.wav`).
- **Radar:** El radar en la parte superior derecha calculará la distancia del enemigo más cercano y pitará como advertencia cuando se acerquen peligrosamente.

## ⚙️ Cómo jugar (Instalación)

No se requiere ningún tipo de servidor ni dependencias complejas. 
Simplemente clona o descarga este repositorio, y **abre el archivo `AlienGame.html` en cualquier navegador web moderno** (Chrome, Firefox, Safari, Edge).
